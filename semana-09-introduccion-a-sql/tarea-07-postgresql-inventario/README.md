# Tarea 07 - Base de Datos PostgreSQL para Inventario

## Nombre de la actividad

Control de inventario básico para una tienda utilizando PostgreSQL.

## Descripción del problema

Una tienda necesita llevar el control de sus productos (código, nombre, categoría, precio, stock y estado) mediante una base de datos que impida códigos repetidos, precios inválidos y existencias negativas.

## Requisitos para ejecutar los scripts

- PostgreSQL instalado (versión 12 o superior)
- pgAdmin o terminal psql
- Permisos para crear bases de datos

## Nombre de la base de datos

`control_inventario`

## Orden de ejecución de los archivos SQL

1. `database/01_creacion.sql` - Crea la base de datos y la tabla
2. `database/02_datos_prueba.sql` - Inserta datos y prueba restricciones
3. `database/03_operaciones.sql` - Consultas, actualizaciones y eliminación
