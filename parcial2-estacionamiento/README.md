# Parcial II - Sistema de Estacionamiento

## Descripción

Sistema de consola para administrar el ingreso y salida de vehículos de un estacionamiento, aplicando POO, colecciones, excepciones y PostgreSQL.

## Temas aplicados

- Programación Orientada a Objetos
- Clases abstractas y herencia
- Sobrescritura y polimorfismo
- ArrayList, HashSet y HashMap
- Manejo de excepciones (try-catch-finally)
- PostgreSQL y SQL

## Estructura del proyecto

parcial2-estacionamiento/
├── src/

│ ├── Automovil.java
│ ├── Motocicleta.java

├── database/

├── evidencias/
├── README.md
└── .gitignore

## Instrucciones para ejecutar

1. Compilar: `javac src/*.java`
2. Ejecutar: `java -cp src MainEstacionamiento`
3. Para la base de datos: ejecutar `estacionamiento.sql` en PostgreSQL
