# Semana 5 - Sistema de Envíos

## Descripción
Aplicación de consola para calcular el costo de envíos nacionales e internacionales, aplicando Programación Orientada a Objetos.

## Objetivo
Desarrollar una aplicación que demuestre el uso de:
- Clases, objetos, atributos y métodos
- Encapsulamiento
- Herencia
- Sobrecarga de métodos
- Sobrescritura de métodos
- Polimorfismo

## Estructura del proyecto
- Envio.java # Superclase
- EnvioNacional.java # Subclase
- EnvioInternacional.java # Subclase
- Main.java # Clase Principal

## Instrucciones para ejecutar
1. Compilar: `javac src/*.java`
2. Ejecutar: `java src Main`
3. Seguir las instrucciones del menú.

## Resultado esperado
- Registrar envíos nacionales e internacionales
- Cálculo automático del costo según el tipo
- Resumen con desglose completo
