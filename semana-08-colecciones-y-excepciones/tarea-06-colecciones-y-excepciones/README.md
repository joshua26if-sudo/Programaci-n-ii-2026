# Semana 8 - Colecciones y Excepciones

## Descripción

Aplicación en Java que permite registrar y analizar las compras realizadas en un hogar, aplicando POO y colecciones de Java.

## Temas aplicados

- Programación Orientada a Objetos
- ArrayList
- HashSet
- HashMap
- Estructuras de control
- Validaciones
