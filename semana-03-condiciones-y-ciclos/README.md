# Semana 3 - Condiciones y Ciclos

## Descripción
Programa de consola que presenta un menú con 5 desafíos lógicos:
1. Generar una secuencia con `for`
2. Conteo regresivo con `while`
3. Analizar números con `break` y `continue`
4. Dibujar pirámide con `for` anidados
5. Validar palabra secreta con `do-while`

## Requisitos técnicos
- Uso de `if`, `else if`, `else`
- Uso de `switch`
- Uso de `for`, `while`, `do-while`
- Uso de `break` y `continue`
- Validaciones numéricas y de texto
