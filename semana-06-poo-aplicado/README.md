## Descripción
Programa para una veterinaria, que calcula la informacion por paciente, solicitando:
- Codigo de paciente
- Nombre 
- Edad en Meses
- Peso en KG

Si es perro: 
- raza

Si es gato:
- Si es de interior

Si es ave:
- Es exotico o no

## Clases Utilizadas
- Mastoca
- Gato
- Perro
- Ave

## Métodos implementados
| Método | Tipo | Función |
|--------|------|---------|
| `actualizarPeso` | `void` | Actualiza el peso siempre y cuando no sea menor a 0 |
| `mostrarInformacion` | `void` | llama los datos solicitados de las clases llamadas |
| `emitirSonido` | `void` | Es un metodo abstracto que llama el sonido de cada clase |
| `calcularCostoConsulta` | `double` | Calcula el costo de la consulta dependiendo las condiciones que se le solicitan |
