# Semana 7 - Sistema de Figuras Geométricas

## Descripción
Aplicación de consola que calcula el área de diferentes figuras geométricas utilizando Programación Orientada a Objetos.

## Figuras implementadas
- **Círculo** - Área = π × radio²
- **Rectángulo** - Área = base × altura
- **Triángulo** - Área = (base × altura) / 2

## Temas aplicados
- Abstracción (clase abstracta)
- Encapsulamiento (atributos private)
- Herencia (extends)
- Sobrescritura (@Override)
- Polimorfismo (Figura[])

## Instrucciones para ejecutar
1. Compilar: `javac src/*.java`
2. Ejecutar: `java -cp src Main`
