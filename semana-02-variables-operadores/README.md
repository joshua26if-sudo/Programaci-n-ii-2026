# Semana 2 - Calculadora de Edad

## Descripción
Programa de consola en Java que solicita al usuario su nombre completo, año de nacimiento y año actual, para calcular:
- Edad aproximada en años.
- Edad aproximada en meses.
- Si es mayor de edad (true/false).

## Datos solicitados
- Nombre completo (String)
- Año de nacimiento (int)
- Año actual (int)

## Cálculos realizados
- Edad aproximada = año actual - año de nacimiento
- Edad en meses = edad aproximada × 12
- Mayor de edad = edad aproximada >= 18

## Instrucciones para ejecutar
1. Clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Ejecutar la clase `CalculadoraEdad.java`.
4. Ingresar los datos solicitados en la consola.
